# Work item: harness-bootstrap

## Цель

- Проблема: в пустом проекте отсутствовал повторяемый безопасный цикл для агентной разработки.
- Ожидаемый исход для пользователя: агент фиксирует намерение и риск до правки, делает малые срезы и передаёт проверяемый результат.
- Не входит в задачу: настройка конкретного CI, стека или внешних сервисов.

## Контракт и доказательства до правки

- Наблюдения: рабочая директория была пустой; локальных правил и тестов не было.
- Гипотеза: файловые инструкции, шаблон work item и read-only gate дадут переносимый базовый процесс.
- Оракул: PowerShell gate запускается, обнаруживает карточку и завершается успешно без настроенных проектных проверок.
- Инварианты / совместимость: скрипт не меняет файлы и не запускает команды, пока они не заданы явно в конфигурации.

## Карта воздействия

- Компоненты и потребители: будущие агенты и разработчики этого репозитория.
- Данные / миграции: нет.
- Безопасность / права / секреты: gate ищет вероятные секреты в diff и блокирует защищённые пути.
- Внешние зависимости: PowerShell; Git используется опционально.
- Риск: низкий.
- Откат: удалить добавленные файлы harness одним коммитом.
