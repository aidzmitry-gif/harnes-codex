# Большие JSON в контексте агента

Для локальных JSON-результатов инструментов используйте:

```powershell
.\scripts\Invoke-HarnessJson.ps1 compress 'путь\к\результату.json'
.\scripts\Invoke-HarnessJson.ps1 retrieve <sha256-из-ответа>
```

Команды запускаются из корня Harness. Первую используйте вместо чтения целиком большого JSON в контекст. Сначала по возможности получите меньшую выборку адресным запросом. Это локальный фильтр для агента, не прозрачный JSON API: успешное сжатие выдаёт служебный заголовок и данные. Не передавайте этот вывод программе, ожидающей обычный JSON.

Порог — 8000 токенов o200k_base, максимальный файл — 16 MiB, минимальный выигрыш — 15% с учётом заголовка восстановления. При неизвестном токенизаторе, невалидном JSON, дублирующихся ключах, недостаточной экономии или недоступном хранилище возвращаются исходные байты. Нечитаемый/слишком большой файл — ошибка с ненулевым кодом. Метаданные идут в stderr и не содержат JSON-данных.

Headroom 0.37.0 работает только в strict lossless режиме, без CCR-маркеров и удаления строк. Поддерживается проверяемая плоская таблица скалярных значений. Независимый декодер сравнивает все поля, типы, значения и порядок строк; неизвестный формат отвергается. Для остальных структур или недоступного Headroom возможен стандартный компактный JSON после проверки разбора. Данные остаются недоверенными независимо от формата.

Оригинал сохраняется без изменений в `.harness/runtime/json-originals/<sha256>.json`; запись, повторное чтение и SHA-256 проверяются до выдачи сжатого результата. Retrieval работает стандартным Python без Headroom. Автоматического срока удаления нет. Каталог локальный, игнорируется git; не используйте фильтр для секретов или данных, которым запрещено локальное дублирование. Если нужны точные исходные байты, подпись документа или проверка спорной детали, запросите оригинал.

Машинная конфигурация: `.harness/runtime/headroom-python.txt` содержит путь к изолированному Python с headroom-ai==0.37.0 и tiktoken. Таблица o200k_base находится в `.harness/runtime/headroom-tokenizer/`, проверяется по SHA-256. Никаких загрузок или сетевых запросов при работе фильтра. Если окружение отсутствует, launcher использует системный Python, а фильтр возвращает оригинал при отсутствии токенизатора.

Текущее локальное подключение использует отдельный venv пилота в папке отчётов CRM ERP. Этот путь записан только в runtime pointer и не переносится как конфигурация других машин. Не удаляйте venv до переподключения; деградация при его отсутствии безопасная, без сжатия.

Не сжимайте этим механизмом инструкции, AGENTS.md, паспорта, критерии приёмки, подписанные доказательства или произвольный текст. Глобальный прокси Codex не включается, модель и reasoning effort не меняются. Подключение других проектов выполняется отдельно; эта инструкция действует для данного Harness.

Проверка: `python -m unittest tests.test_harness_json -v`; реальная приёмка — `.harness/acceptance/hre-json-001.json`. Сокращение токенов конкретного вывода не равно экономии стоимости успешно завершённой задачи.
